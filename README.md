## Sobre o Projeto

O **ObservaRecife** é uma plataforma desenvolvida para o desafio **Observatório de Emprego e Renda do Recife**, proposto na plataforma CORETO.

Atualmente, gestores públicos, pesquisadores e cidadãos dependem de diversas fontes de dados para analisar informações sobre emprego e renda da cidade. Entretanto, muitos desses dados não estão organizados de forma acessível ou detalhada por bairro.

A proposta do projeto é centralizar essas informações em uma única plataforma, facilitando consultas e análises por meio de dashboards, gráficos e filtros interativos.

---

## Problema

A ausência de uma plataforma unificada dificulta:

- O acompanhamento dos indicadores de emprego;
- A análise da distribuição de renda;
- A comparação entre bairros;
- A criação de políticas públicas mais direcionadas;
- O acesso simplificado aos dados pela população.

---

## Objetivo

Desenvolver uma plataforma web capaz de:

- Centralizar informações sobre emprego e renda;
- Disponibilizar dashboards interativos;
- Facilitar consultas por bairro;
- Apoiar pesquisas acadêmicas;
- Auxiliar gestores públicos na tomada de decisões.

---

## Público Beneficiado

- Gestores públicos;
- Pesquisadores;
- Universidades;
- Organizações sociais;
- Analistas de dados;
- População do Recife.

---

## Funcionalidades da Primeira Versão

- Dashboard com indicadores gerais de emprego e renda;
- Consulta de dados por bairro;
- Gráficos comparativos entre regiões;
- Filtros por gênero, faixa etária e setor econômico;
- Exportação de relatórios básicos.
